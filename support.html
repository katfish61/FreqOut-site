User Manual

The FreqOut User Manual covers setup, connecting to an rtl_tcp server, running sweeps, reading the display, and frequency coordination for radio microphone work.

Common issues

SymptomLikely fix
“No rtl_tcp server found”Check the server is running, the IP address is correct, and port 1234 is not blocked by a firewall.
Connected but sweep is instant or shows no dataStale samples in the buffer — disconnect, restart the rtl_tcp server, then reconnect.
Noise floor suddenly much higherTuner overload — reduce gain in ⚙. Switch any transmitters off during the survey.
App shows DEMO watermarkSource picker in ⚙ is set to Demo — change it to rtl_tcp.
App asks for Local Network permissionTap Allow. FreqOut needs this to reach the rtl_tcp server on your network.
Pi rig: can’t SSH after enabling hotspotJoin the FreqOut Wi-Fi from your Mac and SSH to 10.42.0.1.
